# NanoSIEM Database Migrations

This directory contains SQL migrations for the NanoSIEM database schema.

## Migration Files

1. `001_initial_schema.sql` - Core logs table with time partitioning and indexes
2. `002_detection_rules.sql` - Detection rules for threat identification
3. `003_alerts.sql` - Alerts generated by detection rules
4. `004_dashboards.sql` - Dashboard configurations
5. `005_saved_searches.sql` - Saved search queries
6. `006_detection_rule_mode.sql` - Detection rule mode field
7. `007_detection_daily_stats.sql` - Daily detection statistics
8. `008_shared_searches.sql` - Shared search functionality
9. `009_enrichments.sql` - IP enrichment sources and lookup tables
10. `010_feeds.sql` - Data feed configurations
11. `011_apache_feed.sql` - Apache log feed
12. `012_user_agent_field.sql` - User agent field for logs
13. `013_ingest_timestamps.sql` - Ingestion timestamp tracking
14. `014_pg_textsearch.sql` - PostgreSQL text search configuration
15. `015_timescaledb_compression.sql` - TimescaleDB compression settings
16. `016_source_type_column.sql` - Source type column for logs
17. `017_parsers.sql` - Parser management schema
18. `018_melod_settings.sql` - Melod AI settings
19. `019_ai_generated_flag.sql` - AI-generated content flag
20. `020_log_textsearch_config.sql` - Log text search configuration
21. `021_system_settings.sql` - System settings table
22. `022_query_explanations.sql` - Query explanation storage
23. `023_ingestion_errors.sql` - Ingestion error tracking
24. `024_upload_history.sql` - File upload history tracking
25. `025_lookup_tables.sql` - Lookup tables registry for search enrichment
26. `026_scheduled_jobs.sql` - Scheduled data fetch jobs

## Prerequisites

### Required Extensions

The following PostgreSQL extensions should be installed for full functionality:

```sql
-- Required
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- For time-based partitioning management (recommended)
CREATE EXTENSION IF NOT EXISTS pg_partman;

-- For BM25 full-text search (recommended for production)
-- Requires ParadeDB: https://www.paradedb.com/
CREATE EXTENSION IF NOT EXISTS pg_search;

-- For semantic/vector search (optional)
CREATE EXTENSION IF NOT EXISTS vector;
```

## Running Migrations

### Using SQLx CLI

```bash
# Install sqlx-cli
cargo install sqlx-cli

# Create database
sqlx database create

# Run migrations
sqlx migrate run
```

### Manual Execution

Run each migration file in order:

```bash
psql -d nanosiem -f migrations/001_initial_schema.sql
psql -d nanosiem -f migrations/002_detection_rules.sql
psql -d nanosiem -f migrations/003_alerts.sql
psql -d nanosiem -f migrations/004_dashboards.sql
psql -d nanosiem -f migrations/005_saved_searches.sql
```

## Schema Overview

### logs (partitioned by timestamp)
- Time-partitioned table for log storage
- Contains raw log content and JSONB metadata
- Denormalized UDM fields for fast filtering
- Indexes: GIN on metadata, B-tree on UDM fields, FTS on raw_content

### detection_rules
- Stores detection rule definitions
- Supports scheduled and real-time detection
- MITRE ATT&CK tagging support

### alerts
- Alerts generated by detection rules
- Workflow support: new → acknowledged → closed
- Disposition tracking for closed alerts

### dashboards
- Dashboard layout and panel configurations
- Auto-refresh interval support

### saved_searches
- Saved piped query searches
- Optional default time range

### upload_history
- Tracks all file uploads (logs and lookup tables)
- Records filename, size, format, destination, and status
- Supports filtering by date range, type, and status

### lookup_tables_registry
- Registry of user-created lookup tables
- Stores column definitions and primary key info
- Tracks row count and storage size

### scheduled_jobs
- Scheduled data fetch jobs from remote URLs
- Cron-based scheduling with retry policies
- Supports both log ingestion and lookup table updates
